# Proportional Assurance Profiles

Choose the assurance profile before adding validation infrastructure. Apply
repository-local policy first when it is stricter or more specific.

## Diagnostic

Use for exploration, proof search, first-cell calculations, or “no certificate
found.” Record assumptions, limits, and exactly one direct reproducibility
check. Keep protocol verdict and scientific inference null.

Do not add a candidate manifest, exhaustive mutation campaign, frozen runner,
or independent exact-head review. A diagnostic cannot close a scientific claim
or activate a dependency.

## Analytic

Use for a scoped theorem, obstruction, or positive construction that does not
execute a scientific decision. Require a direct substantive check and one
independent reviewer by default. Batch repairs. After two finding-bearing
candidate heads without a claim-changing finding, stop and accept, downgrade,
or obtain explicit project-owner authorization for more review.

Bind review to an exact pushed commit or a deterministic digest of the
scientific surface. Engineering packaging and unrelated base synchronization
do not renew review when that surface is mechanically unchanged.

## Promotion

Use when an exact conclusion becomes scientific evidence, closes a target, or
activates a successor. Bind exact sources and the scientific surface, obtain
one independent scientific review, and test a small set of load-bearing
semantic changes. Prefer 1–15 targeted mutations; do not mutate every scalar or
prose phrase.

Promotion is a parent-boundary operation. Keep diagnostic children lightweight,
then certify only the exact child conclusions the parent consumes. Import child
digests and source hashes instead of rerunning every inherited validator.

## Shared-versus-custom validation

Use repository-level shared code for schema/type checks, source blobs, owned
paths, workflow trigger coverage, deterministic manifests, enums, and text
hygiene. Packet-specific code is reserved for the new mathematics or a
comparator the shared checker cannot express.

When a proof assistant replaces finite algebra certification, delete the
corresponding handwritten algebra validator and redundant mutations. Do not run
both indefinitely.
